# Spectro Constitution

## Permanent principles

- Specification before implementation.
- Explicit artifacts are the source of workflow state and traceability.
- Deterministic validation is preferred over subjective claims.
- Human approval is required for ambiguity, scope changes, high-risk exceptions, and destructive actions.
- Local execution and evidence are the default.
- Existing project conventions are preferred unless the plan documents a justified exception.
- Quality gates must not be weakened to obtain approval.
- Secrets and sensitive data must not be copied into artifacts or reports.

## Minimum quality

- Every in-scope requirement has an acceptance criterion.
- Every requirement has task and validation coverage.
- New behavior has behavior-focused tests where practical.
- Required gates pass on the same code and configuration revision reviewed at the end.
- Unresolved Critical or High review findings block completion.
